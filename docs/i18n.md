# Γλώσσες (Ελληνικά, English, Español)

## Πώς λειτουργεί
- Ελληνικά (προεπιλογή): `/cars` · Αγγλικά: `/en/cars` · Ισπανικά: `/es/cars`.
- Το `src/lib/i18n.js` διαβάζει το πρόθεμα, το αφαιρεί από τη διαδρομή (οι routes βλέπουν πάντα `/cars`) και ορίζει `req.locale`. Οι ανακατευθύνσεις (`res.redirect('/x')`) μένουν αυτόματα στην ίδια γλώσσα.
- Η διαχείριση (`/admin`) και τα emails προς το γραφείο (`views/emails/admin-*.ejs`) είναι **μόνο στα ελληνικά** — δεν μεταφράζονται.
- Κάθε κράτηση αποθηκεύει τη γλώσσα του πελάτη (`bookings.locale`): τα emails, οι σύνδεσμοι πληρωμής/εγγύησης και η σελίδα πληρωμής του Stripe είναι στη γλώσσα του.
- Οι μεταφράσεις είναι λεξικά στο `src/locales/*.js`, με **κλειδί το ακριβές ελληνικό κείμενο**:
  ```js
  module.exports = {
    en: { 'Στόλος': 'Our fleet', 'Κράτηση {ref}': 'Booking {ref}' },
    es: { 'Στόλος': 'Nuestra flota', 'Κράτηση {ref}': 'Reserva {ref}' },
  };
  ```
  Κάθε κλειδί πρέπει να υπάρχει **και στα δύο** (en, es), με τα ίδια `{πεδία}`. Κείμενο χωρίς μετάφραση εμφανίζεται στα ελληνικά.

## Στα templates (EJS)
| Βοηθητικό | Χρήση |
|---|---|
| `t('Κείμενο')` | Μετάφραση απλού κειμένου: `<%= t('Στόλος') %>` |
| `t('Κράτηση {ref}', { ref })` | Με μεταβλητές |
| `th('Δωρεάν ακύρωση έως <strong>{h} ώρες</strong>', { h })` | Κείμενο με απλά tags (`<strong>`, `<em>`, `<a href="{url}">`, `<br>`): **`<%- th(...) %>`**. Οι τιμές των πεδίων γίνονται escape· η μετάφραση πρέπει να έχει τα ίδια tags. Ποτέ `<%-` με `t()`. |
| `u('/cars')` | Σύνδεσμος/`action` φόρμας στη γλώσσα της σελίδας: `href="<%= u('/terms') %>"`. **Κάθε** εσωτερικός σύνδεσμος και κάθε `action` φόρμας της δημόσιας ιστοσελίδας περνά από `u()`. (Όχι για `/admin`, `/css`, `/js`, `/img`, `/uploads`.) |
| `tf(row, 'name')` | Περιεχόμενο από τη βάση στη γλώσσα: `tf(extra, 'name')`, `tf(car, 'description')`, `tf(location, 'name')`, `tf(booking, 'pickup_location_name')`, `tf(x, 'name')` για τα πρόσθετα κράτησης. |
| `format.money()`, `format.label()` | Ήδη στη γλώσσα της σελίδας (π.χ. «€75.00», μεταφρασμένες ετικέτες). Οι ημερομηνίες μένουν ηη/μμ/εεεε. |
| `lt('../partials/terms-content')` | Μεγάλα κείμενα (όροι, απόρρητο): ξεχωριστό αρχείο ανά γλώσσα, `terms-content.en.ejs`, `terms-content.es.ejs`. `<%- include(lt('../partials/terms-content')) %>` (επιστρέφει το όνομα με `.ejs`) |
| `locale` | `'el'`, `'en'` ή `'es'` |
| `t(errors.x)`, `t(f.message)` | Μηνύματα σφάλματος / flash: μεταφράζονται εκεί που εμφανίζονται. |

Τα ίδια βοηθητικά (εκτός από `u`) υπάρχουν και στα emails· εκεί οι σύνδεσμοι γράφονται `<%= baseUrl %>/manage` (το `baseUrl` περιέχει ήδη το πρόθεμα γλώσσας).

## Στον κώδικα (routes, lib)
- Μηνύματα με μεταβλητές προς τον πελάτη: `const { msg } = require('../lib/i18n'); new BookingError(msg('Ελάχιστη ηλικία {age} ετών.', { age }))`. Το `err.message` μένει ελληνικό (για logs)· η εμφάνιση γίνεται με `req.t(err.i18n || err.message)` ή, στο flash, `req.flash('error', err.i18n || err.message)` (το header μεταφράζει).
- Απλά σταθερά μηνύματα (χωρίς μεταβλητές) μένουν ως ελληνικό κείμενο· αρκεί να υπάρχουν στο λεξικό.
- Θέματα emails: `subject: msg('Επιβεβαίωση κράτησης {ref}', { ref })` — το mailer τα μεταφράζει στη γλώσσα του email (της κράτησης ή `locale:` στο `mailer.send`).
- `title:` στα `res.render` είναι ελληνικό κείμενο· το header το μεταφράζει.
- Σελίδα που εμφανίζεται μετά από POST (π.χ. φόρμα με σφάλματα στο `POST /booking`): η επιλογή γλώσσας πρέπει να οδηγεί σε διαδρομή που ανοίγει με GET — `res.locals.languages = languageLinks(req.locale, '/booking/new?...')`.
- Κείμενα που αποθηκεύονται στη βάση στα ελληνικά (π.χ. αιτία ακύρωσης, `failure_reason` εγγύησης) μεταφράζονται εκεί που εμφανίζονται με `t(...)`· πρέπει να είναι σταθερά κείμενα που υπάρχουν στο λεξικό (ή `msg()`), όχι κείμενα με ενσωματωμένες τιμές.

## Ορολογία (για συνέπεια)
| Ελληνικά | English | Español |
|---|---|---|
| κράτηση | booking | reserva |
| παραλαβή / επιστροφή (αυτοκινήτου) | pick-up / return | recogida / devolución |
| σημείο παραλαβής | pick-up location | lugar de recogida |
| εγγύηση | security deposit (deposit) | fianza |
| δέσμευση / αποδέσμευση ποσού | hold (pre-authorisation) / release | bloqueo (preautorización) / liberación |
| εκκαθάριση εγγύησης | deposit settlement | liquidación de la fianza |
| απαλλαγή (συμμετοχή σε ζημιές) | excess | franquicia |
| Πλήρης Απαλλαγή Ευθύνης για Ζημιές (FDW) | Full Damage Waiver (FDW) | Exención total por daños (FDW) |
| πιστωτική / χρεωστική / προπληρωμένη κάρτα | credit / debit / prepaid card | tarjeta de crédito / débito / prepago |
| δικαίωμα υπαναχώρησης | right of withdrawal | derecho de desistimiento |
| Κράτηση με υποχρέωση πληρωμής | Book with obligation to pay | Reservar con obligación de pago |
| τιμοκατάλογος (χρεώσεων) | price list | tarifas |
| χρέωση | charge | cargo |
| ζημιά | damage | daños |
| ΦΠΑ | VAT | IVA |
| Συνήγορος του Καταναλωτή | Greek Consumer Ombudsman | Defensor del Consumidor de Grecia |
| Στόλος | Our fleet | Nuestra flota |
| Η κράτησή μου | My booking | Mi reserva |

Ύφος: αγγλικά βρετανικά, απλά και ευγενικά· ισπανικά της Ισπανίας με «usted». Νομικά κείμενα: πιστή μετάφραση, με τη σημείωση ότι σε περίπτωση διαφοράς υπερισχύει το ελληνικό κείμενο.

## Έλεγχος
`node --test tests/i18n.test.js`: κάθε δημόσια σελίδα και κάθε email προς πελάτη στα αγγλικά και στα ισπανικά δεν πρέπει να έχει ελληνικό κείμενο.

`node --test tests/i18n-sweep.test.js`: κείμενα που παράγει ο κώδικας. Το JavaScript του browser δεν έχει δικά του κείμενα: τα παίρνει μεταφρασμένα από τη σελίδα (π.χ. κάθε `texts.x` του `public/js/dates.js` από το `data-calendar` του `search-form.ejs`, `data-dmy`, `data-confirm`). Ενδείξεις που αποθηκεύονται στη βάση (π.χ. «Πέραν της απαλλαγής: …» στην τεκμηρίωση χρέωσης) μεταφράζονται εκεί που εμφανίζονται· τα ονόματα αρχείων (συνημμένοι όροι, λήψη δεδομένων) είναι στη γλώσσα του πελάτη.
