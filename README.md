# Ιστοσελίδα ενοικίασης αυτοκινήτων

Πλήρης ιστοσελίδα για εταιρεία ενοικίασης αυτοκινήτων: αναζήτηση διαθεσιμότητας, online κρατήσεις, πληρωμές με κάρτα, λογαριασμοί πελατών και πίνακας διαχείρισης για το γραφείο.

**Τεχνολογίες:** Node.js 22.13+, Express, SQLite (ενσωματωμένη στο Node — δεν χρειάζεται ξεχωριστός server βάσης), EJS, Stripe ή Revolut Business, Nodemailer.

---

## Τι περιλαμβάνει

### Για τους πελάτες
- **Αναζήτηση** με σημείο παραλαβής/επιστροφής, ημερομηνίες και ώρες. Εμφανίζονται μόνο τα πραγματικά διαθέσιμα αυτοκίνητα με την **τελική τιμή**.
- **Φίλτρα** (κατηγορία, κιβώτιο, θέσεις) και ταξινόμηση.
- **Σελίδα αυτοκινήτου** με χαρακτηριστικά, απαιτήσεις και υπολογισμό τιμής.
- **Κράτηση** με πρόσθετα (ασφάλεια, παιδικά καθίσματα, επιπλέον οδηγός κ.λπ.), ζωντανή ενημέρωση τιμής, στοιχεία οδηγού και διπλώματος.
- **Πληρωμή** online με κάρτα (μέσω **Stripe** ή **Revolut Business** — Visa, Mastercard, Apple/Google Pay) ή κατά την παραλαβή.
- **Εγγύηση** στην πιστωτική κάρτα: ο πελάτης την εγκρίνει από το κινητό του (σύνδεσμος/QR) ή δεσμεύεται στο POS του γραφείου. Αποδεσμεύεται αυτόματα μετά την επιστροφή.
- **Email επιβεβαίωσης** με όλες τις λεπτομέρειες.
- **«Η κράτησή μου»**: προβολή, εκτύπωση και **ακύρωση** κράτησης με κωδικό + email (και χωρίς λογαριασμό). Αυτόματη επιστροφή χρημάτων στην κάρτα.
- **Λογαριασμός πελάτη**: εγγραφή, σύνδεση («Να με θυμάσαι»), ιστορικό κρατήσεων, αλλαγή στοιχείων/κωδικού, επαναφορά κωδικού με email, λήψη των δεδομένων μου και διαγραφή λογαριασμού (ΓΚΠΔ).
- Σελίδες **Όροι ενοικίασης** (με τιμοκατάλογο χρεώσεων), **Πολιτική απορρήτου**, **Στοιχεία επιχείρησης**, **Παράπονα**, **Συχνές ερωτήσεις**, **Επικοινωνία** (με φόρμα για ερώτηση, παράπονο ή αμφισβήτηση χρέωσης).
- **Νομικές απαιτήσεις**: προσυμβατική ενημέρωση πριν την κράτηση (απαλλαγή ζημιών, εγγύηση, καύσιμο, ακύρωση, ότι δεν υπάρχει δικαίωμα υπαναχώρησης), κουμπί «Κράτηση με υποχρέωση πληρωμής», όροι ως συνημμένο στο email επιβεβαίωσης, καταγραφή της έκδοσης των όρων σε κάθε κράτηση, αυτόματη διαγραφή παλιών προσωπικών δεδομένων.
- Λειτουργεί σε κινητά, tablet και υπολογιστές.

### Για το γραφείο (`/admin`)
- **Πίνακας ελέγχου**: σημερινές παραδόσεις/επιστροφές, επόμενες κρατήσεις, τζίρος μήνα.
- **Κρατήσεις**: αναζήτηση/φίλτρα, παράδοση αυτοκινήτου (με χιλιόμετρα, είσπραξη και έλεγχο εγγύησης), επιστροφή, σημείωση πληρωμής, ακύρωση με (μερική ή πλήρη) επιστροφή χρημάτων, επιστροφές εκτός συστήματος, εσωτερικές σημειώσεις, επαναποστολή email, πλήρες ιστορικό ενεργειών.
- **Εγγυήσεις & χρεώσεις μετά την επιστροφή**: δέσμευση (POS ή online με QR), χρεώσεις καυσίμου/καθυστέρησης/καθαρισμού, χρεώσεις ζημιάς με αποδοχή ή αμφισβήτηση από τον πελάτη, εκκαθάριση (παρακράτηση + αποδέσμευση υπολοίπου), σύνδεσμος πληρωμής για ό,τι δεν καλύφθηκε.
- **Στόλος**: προσθήκη/επεξεργασία αυτοκινήτων με φωτογραφία, τιμή, εγγύηση, ελάχιστη ηλικία. Δέσμευση αυτοκινήτου για σέρβις/βλάβη.
- **Σημεία** παραλαβής με χρέωση (π.χ. αεροδρόμιο), **πρόσθετα**, **εποχικές τιμές** (π.χ. +40% Ιούλιο-Αύγουστο).
- **Χρήστες** (ορισμός διαχειριστών) και **μηνύματα** από τη φόρμα επικοινωνίας (με σήμανση παραπόνων).
- **Παραστατικά (myDATA)**: για κάθε είσπραξη/επιστροφή εμφανίζεται υπενθύμιση έκδοσης απόδειξης, τιμολογίου ή πιστωτικού· καταχωρείτε τον ΜΑΡΚ μόλις εκδοθεί.
- Τηλεφωνικές κρατήσεις: ο διαχειριστής κάνει κράτηση από την ιστοσελίδα όπως ένας πελάτης.

### Κανόνες που εφαρμόζονται αυτόματα
| Κανόνας | Προεπιλογή |
|---|---|
| Χρέωση ανά 24ωρο, περιθώριο καθυστέρησης | 59 λεπτά |
| Ελάχιστος χρόνος πριν την παραλαβή | 2 ώρες |
| Ωράριο παραλαβών/επιστροφών | 08:00 – 22:00 |
| Χρόνος προετοιμασίας μεταξύ ενοικιάσεων | 60 λεπτά |
| Δωρεάν ακύρωση | έως 48 ώρες πριν |
| Έκπτωση διάρκειας | 5% (7+ ημ.), 10% (14+), 15% (28+) |
| Επιστροφή σε άλλο σημείο | 30 € |
| Ελάχιστη ηλικία / χρόνια διπλώματος | ανά αυτοκίνητο / 1 έτος |
| Δέσμευση αυτοκινήτου όσο ο πελάτης πληρώνει | 35 λεπτά |

Όλα αλλάζουν από το αρχείο `.env`. Οι τιμές περιλαμβάνουν ΦΠΑ 24%.

### Ασφάλεια
- Δεν μπορεί να γίνει **διπλή κράτηση** του ίδιου αυτοκινήτου (έλεγχος μέσα σε συναλλαγή βάσης) — ούτε όταν ένα αυτοκίνητο είναι εκπρόθεσμο.
- **Καμία πληρωμή δεν χάνεται**: κάθε σελίδα πληρωμής καταγράφεται· διπλές ή καθυστερημένες πληρωμές επιστρέφονται αυτόματα, και οι επιστροφές που αποτυγχάνουν ξαναδοκιμάζονται.
- Η τιμή υπολογίζεται **πάντα στον server** — ο browser δεν μπορεί να την αλλάξει.
- Τα στοιχεία κάρτας δεν περνούν ποτέ από τον server (Stripe Checkout). Τα webhooks ελέγχονται με υπογραφή και δεν επεξεργάζονται δύο φορές.
- Κωδικοί με bcrypt, προστασία CSRF σε όλες τις φόρμες, όρια προσπαθειών (σύνδεση, επαναφορά κωδικού κ.λπ.), ασφαλή headers (Helmet/CSP), ασφαλή cookies.

## Γρήγορη εκκίνηση (στον υπολογιστή σας)

Χρειάζεστε **Node.js 22.13 ή νεότερο** (συνιστάται η τελευταία έκδοση 22 LTS ή νεότερη) ([nodejs.org](https://nodejs.org)).

```bash
npm install
cp .env.example .env            # και συμπληρώστε τα στοιχεία σας
npm run seed                    # δημιουργεί τη βάση με ενδεικτικά αυτοκίνητα
npm run create-admin -- admin@example.gr "ΙσχυρόςΚωδικός2026"
npm start
```

Ανοίξτε το http://localhost:3000 — και το http://localhost:3000/admin για τη διαχείριση.

> Για δοκιμές στον υπολογιστή, βάλτε `NODE_ENV=development` και `BASE_URL=http://localhost:3000` στο `.env`.

Εκτέλεση των αυτόματων ελέγχων: `npm test`

## Ρυθμίσεις (`.env`)

Όλες οι ρυθμίσεις εξηγούνται μέσα στο [`.env.example`](.env.example). Οι πιο σημαντικές:

- `BASE_URL` — η διεύθυνση της ιστοσελίδας (π.χ. `https://www.rentacar-thessaloniki.gr`).
- `SESSION_SECRET` — τυχαίο μακρύ κείμενο. Δημιουργία:
  `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`
- `COMPANY_*` — επωνυμία, ΑΦΜ, ΓΕΜΗ, διεύθυνση, τηλέφωνο (εμφανίζονται στο footer, στα emails και στους όρους).

### Online πληρωμές: Stripe ή Revolut
Αρκεί **ένας** από τους δύο. Αν ρυθμίσετε και τους δύο, επιλέξτε με `PAYMENT_PROVIDER=stripe` ή `revolut`.

**Stripe**
1. Λογαριασμός στο [stripe.com](https://stripe.com) με ολοκληρωμένη επαλήθευση επιχείρησης.
2. **Developers → API keys**: το *Secret key* στο `STRIPE_SECRET_KEY`.
3. **Developers → Webhooks → Add endpoint**: URL `https://<το-domain-σας>/webhooks/stripe`, γεγονότα `checkout.session.completed`, `checkout.session.async_payment_succeeded`, `checkout.session.expired`, `payment_intent.canceled`, `payment_intent.succeeded`, `charge.expired`. Το *Signing secret* στο `STRIPE_WEBHOOK_SECRET`.
4. Δοκιμές με κλειδιά `sk_test_...` και κάρτα `4242 4242 4242 4242`, μετά live κλειδιά.
5. Η δέσμευση εγγύησης στο Stripe ισχύει **7 ημέρες**. Για μεγαλύτερες ενοικιάσεις ζητήστε από το Stripe «extended authorizations» (έως 30 ημέρες) και βάλτε `STRIPE_EXTENDED_AUTHORIZATION=true`, ή χρησιμοποιήστε Revolut/POS.

**Revolut Business**
1. Στο Revolut Business: **Merchant → API** και αντιγράψτε το *Production Secret key* στο `REVOLUT_SECRET_KEY`.
2. Αφού ανεβάσετε την ιστοσελίδα με HTTPS, τρέξτε `npm run revolut:webhook` και βάλτε το `REVOLUT_WEBHOOK_SECRET` που εμφανίζεται στο `.env`.
3. Για δοκιμές χρησιμοποιήστε λογαριασμό Revolut Business **Sandbox** και `REVOLUT_SANDBOX=true`.
4. Η δέσμευση εγγύησης (προέγκριση) ισχύει έως **30 ημέρες** για ενοικιάσεις αυτοκινήτων.

Χωρίς πάροχο, η ιστοσελίδα δέχεται μόνο «Πληρωμή κατά την παραλαβή» και η εγγύηση γίνεται με το POS.

### Πώς λειτουργεί η εγγύηση
1. **Πριν/στην παραλαβή** (σελίδα κράτησης στη διαχείριση → «Δέσμευση εγγύησης»):
   - **POS**: κάνετε προέγκριση στο τερματικό και καταχωρείτε ποσό και αριθμό έγκρισης, ή
   - **Online**: δημιουργείτε σύνδεσμο. Ο πελάτης σκανάρει το QR (ή τον λαμβάνει με email), αποδέχεται τους όρους και εγκρίνει τη δέσμευση στη σελίδα του Stripe/Revolut. **Χρεωστικές και προπληρωμένες κάρτες απορρίπτονται αυτόματα.**
2. Η παράδοση του αυτοκινήτου δεν επιτρέπεται χωρίς εγγύηση, εκτός αν το επιλέξετε ρητά.
3. **Μετά την επιστροφή** καταχωρείτε τυχόν χρεώσεις:
   - Καύσιμο, καθυστέρηση, καθαρισμός, διαχείριση προστίμων: βάσει του τιμοκαταλόγου των όρων (με ανώτατα ποσά), ο πελάτης λαμβάνει αναλυτικό email.
   - **Ζημιά** ή **άλλη χρέωση**: απαιτείται τεκμηρίωση. Ο πελάτης λαμβάνει email και **αποδέχεται ή αμφισβητεί** online (ή καταγράφετε τη γραπτή του συναίνεση). Χωρίς συναίνεση δεν αφαιρείται από την εγγύηση — αυτό απαιτούν οι κανόνες Visa/Mastercard. Οι ζημιές δεν ξεπερνούν την **απαλλαγή** της κράτησης, εκτός αν αναφέρετε εξαίρεση των όρων (§7).
   - Ποσό εγγύησης μεγαλύτερο από αυτό που είδε ο πελάτης στην κράτηση απαιτεί καταγραφή της συναίνεσής του.
4. **«Εκκαθάριση εγγύησης»**: αφαιρούνται οι αποδεκτές χρεώσεις και το υπόλοιπο αποδεσμεύεται αμέσως. Ό,τι δεν καλύφθηκε μπορεί να το πληρώσει ο πελάτης online από τη σελίδα της κράτησης.
5. Online εγγυήσεις χωρίς χρεώσεις αποδεσμεύονται **αυτόματα** 48 ώρες μετά την επιστροφή (`DEPOSIT_AUTO_RELEASE_HOURS`). Ο πίνακας ελέγχου δείχνει εγγυήσεις που χρειάζονται ενέργεια ή λήγουν.
6. Αν ακυρωθεί μια κράτηση και ο πάροχος δεν απαντήσει στην αποδέσμευση, λαμβάνετε email και η αποδέσμευση ξαναδοκιμάζεται αυτόματα κάθε 5 λεπτά.

> **Ποιον πάροχο να διαλέξω;** Για ενοικιάσεις άνω των 7 ημερών προτιμήστε **Revolut** (προέγκριση έως 30 ημέρες) ή το **POS** — η απλή δέσμευση του Stripe λήγει σε 7 ημέρες. Αν αλλάξετε πάροχο (`PAYMENT_PROVIDER`), **κρατήστε ρυθμισμένα τα κλειδιά του παλιού** μέχρι να κλείσουν όλες οι εγγυήσεις και επιστροφές που έγιναν μέσω αυτού.
> Το Revolut δεν δέχεται `BASE_URL` σε `localhost`: σε τοπικές δοκιμές ο πελάτης μένει στη σελίδα του Revolut μετά την πληρωμή (η κράτηση επιβεβαιώνεται κανονικά από το webhook ή τον περιοδικό έλεγχο).

### Emails (SMTP)
Συμπληρώστε `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` από τον πάροχο email σας (π.χ. Google Workspace, Microsoft 365, Brevo, Mailgun, Amazon SES). Το `ADMIN_NOTIFY_EMAIL` λαμβάνει ειδοποίηση για κάθε νέα κράτηση και μήνυμα.
Για να μην καταλήγουν τα emails στα spam, ρυθμίστε SPF/DKIM στο domain σας (οδηγίες δίνει ο πάροχος).

## Ανέβασμα στο internet

### Επιλογή Α: Docker (VPS, π.χ. Hetzner, DigitalOcean, Contabo)
```bash
cp .env.example .env    # συμπληρώστε, με NODE_ENV=production
sudo chown -R 1000:1000 data   # ο φάκελος δεδομένων πρέπει να ανήκει στον χρήστη της εφαρμογής
docker compose build
docker compose run --rm app npm run seed
docker compose run --rm app npm run create-admin -- admin@example.gr "ΙσχυρόςΚωδικός2026"
docker compose up -d
```
Τα δεδομένα (βάση + φωτογραφίες) αποθηκεύονται στον φάκελο `./data`. Η εφαρμογή ακούει μόνο τοπικά (`127.0.0.1:3000`)· από το internet είναι προσβάσιμη μόνο μέσω του reverse proxy.

> Πολλοί πάροχοι VPS (π.χ. Hetzner, DigitalOcean) μπλοκάρουν την εξερχόμενη θύρα SMTP 25/587 σε νέους λογαριασμούς. Χρησιμοποιήστε υπηρεσία email με θύρα 465/2525 ή ζητήστε άρση του περιορισμού.

Μπροστά από την εφαρμογή βάλτε έναν reverse proxy με **HTTPS** — το πιο απλό είναι το [Caddy](https://caddyserver.com) (βγάζει αυτόματα πιστοποιητικό SSL):
```
www.example.gr {
    reverse_proxy localhost:3000
}
```
και κρατήστε `TRUST_PROXY=1` στο `.env`.

### Επιλογή Β: Πλατφόρμες (Render, Railway, Fly.io)
Ανεβάστε το repository, ορίστε τις μεταβλητές του `.env` στις ρυθμίσεις της πλατφόρμας και συνδέστε έναν **μόνιμο δίσκο (persistent volume)** στο `/app/data` (αλλιώς η βάση χάνεται σε κάθε επανεκκίνηση). Εντολή εκκίνησης: `npm start`.

### Αντίγραφα ασφαλείας
Όλα τα δεδομένα βρίσκονται στον φάκελο `data/`. Κάντε καθημερινό αντίγραφο, π.χ. με cron:
```bash
sqlite3 /path/to/data/app.db ".backup '/backups/app-$(date +%F).db'"
tar czf /backups/uploads-$(date +%F).tgz /path/to/data/uploads
```

## Λίστα ελέγχου πριν το άνοιγμα

**Νομικά / λογιστικά (δεν γίνονται από την ιστοσελίδα)**
- [ ] **Δικηγόρος**: έλεγχος όρων ενοικίασης, πολιτικής απορρήτου, κειμένων εγγύησης/ζημιών και του τιμοκαταλόγου, σύμφωνα με το ασφαλιστήριο.
- [ ] **Λογιστής**: τύποι παραστατικών (ΑΠΥ / τιμολόγιο / πιστωτικό) και πάροχος ηλεκτρονικής τιμολόγησης ή ΦΗΜ, **υποχρεωτική ηλεκτρονική τιμολόγηση B2B** (ημερομηνία έναρξης για την επιχείρησή σας), **Ψηφιακό Πελατολόγιο** για ενοικιάσεις οχημάτων, διασύνδεση POS–ταμειακής, όριο μετρητών (`CASH_LIMIT`).
- [ ] **Ασφαλιστική**: ότι η απαλλαγή (`excess` ανά αυτοκίνητο) και η «Πλήρης Απαλλαγή» αντιστοιχούν στο ασφαλιστήριο· τα κείμενα δεν παρουσιάζουν την FDW ως ασφάλιση.
- [ ] **ΜΗΤΕ** και άδεια γραφείου ενοικίασης σε ισχύ (`COMPANY_MHTE`).
- [ ] Stripe/Revolut: δηλώστε δραστηριότητα «ενοικίαση αυτοκινήτων» (MCC 7512) κατά την ενεργοποίηση.

**Τεχνικά**
- [ ] Στοιχεία επιχείρησης (`COMPANY_*`) και `BASE_URL` στο `.env` (σε παραγωγή η εφαρμογή δεν ξεκινά χωρίς ΑΦΜ, ΓΕΜΗ, ΜΗΤΕ, διεύθυνση, τηλέφωνο, email)
- [ ] Ισχυρό `SESSION_SECRET`, `NODE_ENV=production`, HTTPS
- [ ] Πραγματικά αυτοκίνητα, φωτογραφίες, τιμές και εγγυήσεις από το `/admin/cars` (απενεργοποιήστε τα ενδεικτικά)
- [ ] Σημεία παραλαβής, πρόσθετα και εποχικές τιμές
- [ ] **Όροι ενοικίασης** (`views/partials/terms-content.ejs`) και **Πολιτική απορρήτου** (`views/pages/privacy.ejs`) μετά τον έλεγχο του δικηγόρου· ενημερώστε το `TERMS_VERSION`
- [ ] Τιμοκατάλογος (`FUEL_PRICE_PER_LITRE`, `CLEANING_FEE` κ.λπ.) και απαλλαγή ανά αυτοκίνητο
- [ ] Stripe ή Revolut σε live λειτουργία και webhook ρυθμισμένο (η εφαρμογή προειδοποιεί στην εκκίνηση αν λείπει)
- [ ] `ADMIN_NOTIFY_EMAIL`: πού θα έρχονται οι ειδοποιήσεις του γραφείου
- [ ] Δοκιμαστική εγγύηση: online (QR) και POS → επιστροφή → εκκαθάριση
- [ ] SMTP: δοκιμαστική κράτηση και έλεγχος ότι έρχεται το email
- [ ] Δοκιμαστική κράτηση → ακύρωση → επιστροφή χρημάτων
- [ ] Αντίγραφα ασφαλείας
- [ ] Έκδοση παραστατικών: η ιστοσελίδα **δεν** εκδίδει αποδείξεις/τιμολόγια (myDATA). Εκδίδονται από το πρόγραμμα τιμολόγησης/ΦΗΜ σας· ο πίνακας ελέγχου δείχνει ποια εκκρεμούν.

## Πώς λειτουργεί μια κράτηση

```
                ┌─────────── κάρτα ───────────┐
Κράτηση ──►  Αναμονή πληρωμής ──(πληρωμή)──► Επιβεβαιωμένη ──(παράδοση)──► Σε εξέλιξη ──(επιστροφή)──► Ολοκληρώθηκε
   │              │                              ▲     │
   │              └─(35' χωρίς πληρωμή)─► Έληξε  │     └─(ακύρωση)──► Ακυρώθηκε (+ επιστροφή χρημάτων)
   └── πληρωμή στην παραλαβή ───────────────────┘
```

## Δομή κώδικα

```
src/
  server.js            εκκίνηση & περιοδικές εργασίες
  app.js               ρύθμιση Express (ασφάλεια, sessions, routes)
  config.js            ρυθμίσεις από το .env
  db/                  σχήμα βάσης, αρχικά δεδομένα, δημιουργία διαχειριστή
  lib/                 λογική: τιμές, διαθεσιμότητα, κρατήσεις, πληρωμές, εγγυήσεις, emails
  lib/providers/       σύνδεση με Stripe και Revolut
  routes/              σελίδες: δημόσιες, κράτηση, λογαριασμός, διαχείριση, webhooks
```
